# Stella Mao · UX Research Portfolio

Static site, no build step. Open `index.html` in a browser or deploy the whole folder to GitHub Pages.

## Structure

```
index.html             Home: hero, case cards, research cycle, methods, more work, about
sage.html              Case 01 · SAGE usability study
automation-bias.html   Case 02 · AI-first vs. human-first experiment
vr-dental.html         Case 03 · VR co-design for children's dental anxiety
aura-focus.html        Case 04 · Aura Focus, end-to-end research cycle
css/style.css          All styles (light and dark themes)
js/main.js             Copy-email button
StellaMao_Resume.pdf   One-page UXR resume, linked from the nav and contact area
images/                All photos and figures
```

The header and the contact footer are repeated in every HTML file. If you change them, change all five files.
